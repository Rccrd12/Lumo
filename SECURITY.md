# Security

Lumo approves permissions for coding agents, sends email and reads files on
your computer, so a weakness in it matters. Please report one privately.

## Reporting

Use GitHub's private vulnerability reporting: **Security → Report a
vulnerability** on [Rccrd12/Lumo](https://github.com/Rccrd12/Lumo/security/advisories/new).
Please don't open a public issue for it.

Say what the problem is, the version of Lumo (Settings → About) and the
steps that show it. You'll get an answer within a week.

## Supported versions

Only the latest release of Lumo for Windows gets security fixes.
